This project is a pure HTML5 + CSS3 build — no JavaScript, no frameworks, just clean structure and handcrafted styling.
It focuses entirely on vibe-based UX, not commercial elements. The whole idea is to make the user feel the brand the moment they land on the page — warm tones, smooth interactions, subtle motion, and zero salesy pressure.

I pushed my styling skills further in this one:

custom hover animations

layered shadows

soft transitions

layouts using Flexbox and Grid

a fully designed header/footer system

consistent color palette and typography

The website isn’t trying to “sell”; it’s trying to communicate a feeling — something personal, musical, and atmospheric.
This was a big step forward for me
